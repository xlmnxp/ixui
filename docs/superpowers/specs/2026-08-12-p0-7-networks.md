# P0-7: Network Config Editor + DHCP Leases + Forwards

**Date:** 2026-08-12
**Status:** Approved for implementation

## Overview

Network pages beyond name/type/description: a full config editor (bridge/ipv4/ipv6/MTU keys), a DHCP leases viewer, and port forwards CRUD.

## Decisions

| Topic | Decision |
|---|---|
| Edit dialog | Extended to a config KeyValueEditor (same component as instance config) + description; save via `infraApi.updateNetworkConfig(name, { config })`; key descriptions from `/1.0/metadata` where available |
| Leases | Networks page: "Leases" action per managed network → table (address, hostname, MAC, type, expires) from `GET /networks/{name}/leases?recursion=1` (new `infraApi`-style method via the existing client — add `listLeases` to `NetworkExtrasApi`) |
| Forwards | "Forwards" action per network → list + create/delete via `networkExtrasApi.listForwards/createForward/deleteForward`; create dialog: listen address, description, ports |
| Types | `Lease { address; hostname; hwaddr; type; expires_at }` |
| Safety | Config save only on managed networks; leases/forwards hidden on unmanaged |

## Testing

- Config editor save posts { config } and description
- Leases table renders from mock; hidden for unmanaged
- Forward create/delete flow
