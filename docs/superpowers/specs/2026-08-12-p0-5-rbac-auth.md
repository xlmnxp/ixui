# P0-5: RBAC UI + Trust-Token Onboarding + Logout

**Date:** 2026-08-12
**Status:** Approved for implementation

## Overview

Identity/groups/permissions pages on Incus fine-grained authz, certificate trust-token issuance for CLI onboarding, and a logout flow.

## Decisions

| Topic | Decision |
|---|---|
| Routes | `/auth` (Identities tab), `/auth/groups`, `/auth/permissions` — vertical-tabbed page |
| Identities | Table (id, type, groups) from `authApi.listIdentities()`; view/edit group membership |
| Groups | Table + create/edit dialog (name, description, permission checkboxes from `authApi.listPermissions()`) + delete |
| Permissions | Read-only table of available permissions (entity type, actions) — documentation surface |
| Trust tokens | New section (server page or certificates page): "Issue join token" — description + expiry → `certificatesApi.createToken` → show the token with a copy button; pending joins surfaced via `certificatesApi.list()` |
| Logout | Auth store gains logout: clears session — for OIDC this is `GET /oidc/logout` redirect; for TLS-cert users the logout button explains removing the client cert. `startOidcLogout()` in auth/login.ts |
| Degradation | Pages hide mutating controls when the caller lacks permissions (parse `access_entitlements` on the identity when present; otherwise best-effort) |

## Testing

- Identities/groups tables render from mocked api
- Group create/edit with permission checkboxes posts the body
- Token issuance shows the returned token; copy button copies
- Logout triggers the oidc/logout redirect for OIDC status
