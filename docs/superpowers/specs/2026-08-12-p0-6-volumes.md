# P0-6: Storage Volumes CRUD + Snapshots + Attach + ISO Import

**Date:** 2026-08-12
**Status:** Approved for implementation

## Overview

Custom volume management: create/update/resize/rename/delete, volume snapshots, attach a custom volume to an instance (VM data disks), and ISO import for VM installs.

## Decisions

| Topic | Decision |
|---|---|
| Storage page | Pools table keeps; **Volumes** tab per pool becomes full CRUD: create dialog (name, content type custom/iso, size, config), row actions Edit/Resize/Rename/Delete, volume snapshots table per volume (create/restore/delete) |
| Data | `VolumesApi` (created in the API wave) |
| Attach | Instance Devices tab + "Attach volume" action on the volume row: pick instance (project) → adds a disk device `{ type: "disk", pool, source: <vol>, path: "/mnt/<vol>" }` via `instancesApi.update` (after P0-1 lands, via the devices editor; before that, direct update) |
| ISO import | Storage page: "Import ISO" button → file picker → `VolumesApi.create` with `type: "iso"` + upload (raw POST with the file body to /storage-pools/{pool}/volumes/{type}/{name} with `Content-Type: application/octet-stream`) |
| Sizing | Resize dialog validates new size ≥ current, config `size` key |

## Testing

- Volume create/rename/resize/delete flows call the right APIs
- Snapshot create/restore/delete per volume
- Attach adds the disk device to the instance update body
- ISO import posts the file body
